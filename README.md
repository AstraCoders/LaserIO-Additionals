# LaserIO Additionals

LaserIO Additionals is a lightweight addon for LaserIO that adds compatibility cards for Applied Energistics 2, PneumaticCraft: Repressurized, and Refined Storage.

## Features

### Applied Energistics 2 Channel Card

Connects AE2 networks through LaserIO nodes. Cards using the same LaserIO channel can form a bidirectional AE2 connection across the laser network.

### Refined Storage Bridge Card

Connects a Refined Storage network beside a LaserIO node to other Refined Storage networks linked through LaserIO nodes using the same LaserIO channel. Use one card per LaserIO node, on the face beside the Refined Storage network.

### PneumaticCraft Pressure Card

Transfers pneumatic pressure between LaserIO nodes using Insert and Extract modes.

The card includes configurable:

- LaserIO channel
- Transfer mode
- Pressure transfer rate
- Card overclockers for increased pressure transfer rate

### Native LaserIO Interface

The cards use interfaces and controls designed to match LaserIO's existing cards, including channel colors, tooltips, inventory access, and in-node configuration.

### Optional Integrations

Applied Energistics 2, PneumaticCraft, and Refined Storage are optional. Each integration loads only when its corresponding mod is installed.

### Lightweight Addon

The addon focuses entirely on extending LaserIO's compatibility without changing the progression or mechanics of the supported mods.
